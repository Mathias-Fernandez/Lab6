# Mini ERP – App de login y productos

Proyecto para la tarea de Deployment a GitHub Pages (TE)

## Cómo correr
npm install
npm run dev


## Deploy
1. Repo público en GitHub.
2. git init / git add . / git commit -m "Proyecto inicial" / git branch -M main
3. git remote add origin <URL_DE_TU_REPO>
4. git push -u origin main
5. Settings → Pages → Source: "GitHub Actions"
6. El workflow en .github/workflows/deploy.yml publica solo en cada push a main/master.
7. Link: https://<tu-usuario>.github.io/<nombre-del-repo>/
